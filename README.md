# 📊 Data Warehouse & Analytics Project

An end-to-end **SQL Server data warehousing and analytics project** focused on transforming raw ERP and CRM data into a structured data warehouse and generating business insights using SQL.

## 🎯 Project Overview

This project demonstrates a complete analytics workflow:

- Importing data from **ERP and CRM CSV files**
- Cleaning and transforming raw data
- Integrating multiple data sources
- Building a centralized **data warehouse**
- Creating analytical SQL queries
- Analyzing **customer behavior, product performance, and sales trends**

## 🏗️ Project Workflow

ERP Data + CRM Data  
↓  
Data Cleaning & Transformation  
↓  
Data Warehouse  
↓  
SQL Analytics  
↓  
Business Insights

## 🛠️ Tech Stack

- **SQL Server** – Data warehouse and database
- **SQL** – Data transformation and analytics
- **SSMS** – Database development and management
- **CSV** – Source data
- **Git & GitHub** – Version control

## 📌 Key Areas

### Data Warehousing

- Source data integration
- Data cleaning and quality checks

- Analytical data preparation

### Data Analytics

- Customer behavior analysis
- Product performance analysis
- Sales trend analysis
